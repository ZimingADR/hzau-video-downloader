# 狮山智学录播视频下载器 (HZAU Video Downloader)

本项目是一个专门针对华中农业大学“狮山智学”平台开发的 Tampermonkey 用户脚本。它可以帮助学生更加便捷、高效地将录播课视频下载到本地，支持单视频自由视角下载和整门课程的批量一键下载。

## ✨ 核心特性

- **一键批量下载**：在课程录播列表一键拉取整门课的所有视频，彻底解放双手。
- **多视角自由选择**：全面支持并解析教师机位、板书机位、学生机位，单集或批量均可自由勾选与组合。
- **专属偏好设置中心**：内置可视化设置面板，可自由调节后台**并发下载数目**、自定义**下载保存目录**，以及单独配置单视频和批量下载的**默认视角勾选状态**。所有配置均自动进行本地持久化保存。
- **全局进度与智能预估时间 (ETA)**：不仅拥有针对单个视频的微观进度监控，还在面板顶部提供了**全局大盘下载进度**、**实时汇聚总网速**以及**整体预估剩余时间**。让每一次批量下载的时长都在您的精确掌握之中。
- **跨域直连免代理**：直接利用浏览器的原生认证状态抓取直链，无需任何额外的软件配置或代理中转，原生稳定极速。

## 🌐 适用网站
本脚本专用于华中农业大学狮山智学资源平台：
- `https://resc.hzau.edu.cn`

## 🛠️ 安装与使用方法

1. **安装 Tampermonkey 插件**
   前往您的浏览器插件商店（Chrome 网上应用店、Edge 附加组件等）搜索并安装 **Tampermonkey** 插件。
2. **一键安装本脚本**
   点击下方链接，Tampermonkey 会自动弹出安装界面：
   👉 **[点击这里一键安装脚本](https://raw.githubusercontent.com/ZimingADR/main/master/hzau-video-downloader.user.js)** 
3. **本地安装（开发者使用）**
   将本项目下的 `hzau-video-downloader.user.js` 的源码复制，打开 Tampermonkey 管理面板，选择“添加新脚本”，粘贴覆盖代码后保存即可。
4. **开始使用**
   - **单视频下载**：在狮山智学平台点击进入任意一个录播视频的播放页面（带有播放器的页面），页面右侧边缘会弹出一个蓝色的 `下载视频` 浮动按钮。点击后即可选择机位视角进行下载。
   - **批量下载**：在 `教学应用-资源中心-我的空间-<课程名>` 页面，右侧会多出一个 `📦 批量下载录播` 按钮，点击即可弹出批量下载筛选框，全选后开始后台并发下载。

## 📡 API 原理解析
脚本主要通过拦截和复用平台的两大内部接口来获取视频直链：
1. **课程录播列表 API**: 
   - 路径：`/resource-center/studentSpace/getStudentResourceList`
   - 作用：传入 `courseId` 获取整门课程中含有的所有视频的 `resourceId` 和名称列表。
2. **单视频详情 API**: 
   - 路径：`/resource-center/videoclass/videoClassInfo`
   - 作用：传入 `resourceId` 获取该录播课对应的所有可用机位（`videoList`）及其储存在 S3 服务器上的直链 `videoPath`。

脚本使用原生 `GM_download` 发起文件下载，并监听 `onprogress` 事件进行精准的 ETA 时序计算。
